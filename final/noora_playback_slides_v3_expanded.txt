### SLIDE 2: SYSTEM OVERVIEW - COMPREHENSIVE
- Network-transparent and vendor-neutral monitoring system designed for operator-scale infrastructure
- Combines network monitoring and reporting under one unified environment
- Serves both network planning units and network monitoring/operations teams
- Key statistics:
  - Over 2,500,000 indicator statistics updated every 180 seconds
  - Over 1,000,000 lines of CSV-formatted inventory data processed nightly
  - Approximately 5,000 devices monitored with over 4,200 active monitoring points
  - 140,000 enabled objects and 1,400,000 disabled objects in SevOne database
  - 171,000 object licenses with 1.50 USD per license cost (before discounts)
  - Over 100,000 lines of custom code developed by Telia and Tietoevry over 3+ years
  - 1,800 Qlik reporting groups containing 18,000 monitored objects
  - 200,000+ objects distributed across 4 collector peers
- System characteristics:
  - Fully automated end-to-end workflow from input to output
  - No constant manual interactions required in normal operations
  - High reliability with critical issues occurring only once every 2 years
  - Non-critical issues occurring once every 6 months
  - Provisioning issues occurring approximately once per month
  - Typical device provisioning time: 5-15 minutes depending on configuration

**NOORA PROVISIONING PHASES:**
- Phase 1: Loader (Device validation and discovery)

- Phase 4: Link (Link object creation for historical continuity)

**POST-PROVISIONING:**
- Alarm policy application
- Threshold monitoring activation
- Reporting group assignment
- Data export configuration
- Ongoing monitoring and maintenance

- Key characteristics:
  - Fully automated process (no manual intervention normally)
  - Rulebook-driven decision making
  - Error handling and recovery mechanisms
  - Comprehensive logging and auditing
  - Integration with multiple systems
  - Typical completion time: 5-15 minutes
  - Exceptional cases may require manual intervention

     - Monitoring eligibility assessment
  3. Role assignment execution:
     - "Managed" devices (SNMP-pollable)

     - Network segment rules
