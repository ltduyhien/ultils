# Noora Project - File and Folder Overview

## Folders

### `kt_sessions`
Contains all knowledge transfer (KT) session files and related PNG images. These files document various aspects of the Noora system, including architecture, operations, and specific modules.

### `materials`
Contains supplementary materials such as historical emails, slides, and provisioning documentation. These files provide context and background information about the Noora project.

### `shadow_sessions`
Contains files related to shadow sessions, which likely involve observations or secondary documentation about the Noora system.

## Summary
The Noora project is a comprehensive system with detailed documentation spread across multiple knowledge transfer sessions, supplementary materials, and shadow sessions. The files cover various aspects of the system, including architecture, operations, provisioning, and specific modules. The `materials` folder contains critical documents such as the Noora slider presentation (converted to JPG) and the device provisioning process documentation, which are essential for understanding the project's architecture and operational workflows. The `list.md` file serves as a quick reference guide for navigating the project's documentation.
